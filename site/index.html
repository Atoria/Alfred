From a question to a pull request

The whole path happens on the page people are already looking at. Nobody has to find the file first.

  1. Ask how it's calculated

    Alfred's agent reads the controllers, components, scopes and queries behind the value, then answers in plain words. Ask follow-ups right underneath, like “does this include refunded orders?”

    • The first answer takes 10 to 40 seconds, then it's saved and instant for everyone.
    • Your team can verify answers, so people see “Verified” instead of “AI-generated”.

  2. Describe a change

    Say what you want in your own words: “make this a green badge when it's above 2.5%”. Alfred finds the code and proposes the smallest edit that does it, shown as a diff. Nothing is written yet.

  3. Preview it on the real page

    See the change rendered with your real data. Only you see it, and the code isn't touched. The preview bar lets you open a ticket or a pull request, refine the change, or stop.

  4. Send it as a ticket and a pull request

    One form creates the ticket in your tracker and opens a draft pull request with the code, linked both ways. The ticket carries the request, the diff, screenshots and where it lives in the code.

    • Trackers: Jira, GitHub Issues, GitLab, Linear, Trello, ClickUp, Asana or your own.
    • Pull requests: GitHub, GitLab or Bitbucket, through their APIs. No git on the server.

  5. A developer reviews and merges

    The ticket and the pull request are created together, so the developer gets the request, the context and the code in one place.

Works with what you have

Laravel
Laravel 11, 12 and 13 on PHP 8.2 or newer.
Front end
Blade, Livewire, Filament, and Inertia with Vue, React or Svelte.
AI models
OpenAI built in. Claude, Gemini, Groq, Ollama, OpenRouter and more through LarAgent, with fallback providers.
Costs
Usage is recorded per day, person and kind. Optional daily budgets, overall and per person. Saved answers cost nothing.
Ticket trackers
Jira, GitHub Issues, GitLab, Linear, Trello, ClickUp and Asana, or your own. Without one, copy the ticket as Markdown.
Pull requests
Draft pull requests on GitHub, GitLab or Bitbucket, or your own git host.
Multi-tenant apps
stancl/tenancy and spatie/laravel-multitenancy. Everything stays in its tenant.
Testers on staging
Visitors who aren't signed in can use Alfred on staging through a private access link, with their own rate limits. Never in production by default.
Your branding
Your own name, icon and colour, light and dark mode. Rename it to anything you like.
Command line
php artisan alfred:doctor checks your setup without printing secrets. php artisan alfred:usage shows what the AI used.

Who it's for

People who rely on the numbers

Operations, finance and support get answers on the spot, from the code that actually produces the figure.

People who shape the product

Product managers, designers and testers describe a change, see it on the page and hand it over as a ticket or pull request.

Developers

Fewer “how is this worked out?” messages, and tickets that arrive with the diff and the file.

Careful with your code and your data

Hidden until you choose

Nobody sees Alfred until you list them by email or give them a gate. Everyone else gets no button and no script.

Reads only what you allow

The agent reads the folders you list. It never reads .env, keys, credentials, storage, vendor or .git, and it can't change providers, policies or middleware.

Nothing written unless you say so

Propose mode never writes on the server. Previews exist only in your own session.

Your data stays on your server

By default the AI sees your code, never the values on the page. Anything that looks like a credential is removed first.

Set it up in four lines

Install, migrate, add your key and say who may use it. Sign in, reload, and the ? appears in the corner.

Every option is in the configuration reference. To check your setup, run php artisan alfred:doctor.

composer require atoria/alfred
php artisan migrate

# .env
ALFRED_ENABLED=true
ALFRED_OPENAI_API_KEY=sk-...
ALFRED_USERS=*@your-company.com
ALFRED_VERIFIERS=you@your-company.com
